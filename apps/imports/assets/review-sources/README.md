# Логотипы площадок с отзывами

Файлы берутся отсюда и подставляются командой `seed_demo` в карточки раздела
«Оценки на площадках». В админке их можно заменить: поле «Логотип площадки» у
записи рейтинга перекрывает то, что положил сюда `seed_demo`.

| Файл | Что это | Источник | Лицензия |
|------|---------|----------|----------|
| `2gis.svg` | Логотип 2ГИС, русское начертание | [Викисклад](https://commons.wikimedia.org/wiki/File:2GIS_logo_(Russian).svg) | Общественное достояние (простая типографика), товарный знак 2ГИС |
| `yandex.svg` | Логотип Яндекс Карт, русское начертание | [Викисклад](https://commons.wikimedia.org/wiki/File:Yandex_Maps_RU_wordmark.svg) | Общественное достояние (простая типографика), товарный знак Яндекса |

Авторские права на такие начертания не распространяются — охраняется только
товарный знак. Здесь логотип стоит рядом со ссылкой на карточку самой компании
на этой площадке, то есть обозначает площадку, а не выдаёт её за нашу: такое
использование знака допустимо. Ставить эти логотипы куда-то ещё — например в
шапку сайта или рядом с услугами — нельзя.

Из файлов убрано лишнее: объявление внешнего DTD и комментарии редактора.
