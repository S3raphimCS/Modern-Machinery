# Функции по итогам разбора конкурентов — дизайн-документ

Дата: 16 сентября 2026 года.
Основание: [`docs/KONKURENTY.md`](../../KONKURENTY.md) — разбор сайтов
Сумитек, Русбизнесавто и НСК.

## Что делаем и почему

Пять функций, закрывающих самые заметные разрывы с конкурентами. Порядок —
по влиянию на сделку.

| № | Функция | У кого есть | Чем закрываем |
|---|---|---|---|
| 1 | Лизинг и кредит | Русбизнесавто | Раздел, партнёры, **калькулятор платежа** — его нет ни у кого |
| 2 | Прикрепление файла к заявке | Сумитек | Вложения к заявке с защищённой отдачей |
| 3 | Отзывы | Все трое | Свои отзывы + рейтинги площадок + виджет Яндекса |
| 4 | Подборки по диапазонам характеристик | Русбизнесавто | Расширение существующих посадочных |
| 5 | Доставка | Русбизнесавто | Раздел и блок на карточке техники |

Вне объёма: PDF-брошюры (нет самих файлов), избранное, корзина, личный
кабинет (этап 2), коллтрекинг, квиз-подбор.

## 1. Лизинг и кредит

Новое приложение `apps/financing/` — отдельная предметная область со своей
арифметикой, в существующие приложения не вписывается.

### Модели

```
LeasingPartner    название, логотип, ссылка, примечание,
                  порядок, активен
LeasingTerms      синглтон: аванс от/до %, срок от/до месяцев,
                  удорожание по умолчанию %, срок решения
```

Условия вынесены в редактируемый синглтон, потому что они же служат
границами и значениями по умолчанию для калькулятора: менеджер меняет
«аванс от 10%» в админке, и калькулятор считает по новым правилам.

### Расчёт

В России лизинг котируют через **удорожание в год**, а не через процентную
ставку. Формула:

```
аванс       = Стоимость × Аванс% / 100
финансируем = Стоимость − аванс
переплата   = финансируем × Удорожание% / 100 × Срок / 12
платёж      = (финансируем + переплата) / Срок
итого       = Стоимость + переплата
```

Контрольный пример: стоимость 18 000 000 ₽, аванс 20%, срок 36 месяцев,
удорожание 7% в год → аванс 3 600 000, финансируем 14 400 000, переплата
3 024 000, платёж **484 000 ₽/мес**, итого 21 024 000 ₽.

Расчёт — чистая функция рядом с калькулятором стоимости владения,
покрывается тестами без запросов и форм.

### Где появляется

- раздел `/lizing/`: условия, партнёры, калькулятор, заявка;
- **строка «от N ₽/мес в лизинг» на карточке техники**, где известна цена —
  именно это продаёт, а не страница с условиями;
- новый тип заявки `leasing`, расчёт сохраняется в `payload`.

Маршрутизация и письма уже готовы, добавляется правило для нового типа.

### Ограничение

В демонстрационных данных партнёры — обезличенные названия. Перечислять
реальные лизинговые компании партнёрами, когда договора нет, — заявление о
существующих организациях. Заказчик впишет своих.

## 2. Прикрепление файла к заявке

### Модель

```
LeadAttachment    заявка, файл, исходное имя, размер, дата
```

Отдельная модель, а не поле: снабженец присылает и техническое задание, и
список артикулов. Ограничение — три файла на заявку.

### Допустимые форматы

`pdf, doc, docx, xls, xlsx, jpg, jpeg, png`, до 10 МБ на файл.

Excel обязателен: списки артикулов присылают именно так.

### Защита

Сейчас nginx раздаёт `/media/` напрямую. Спецификация одного клиента не
должна открываться по угаданной ссылке, поэтому:

- файлы хранятся в `media/private/leads/`, **nginx этот путь не отдаёт**;
- имя на диске случайное, исходное хранится в базе отдельным полем;
- скачивание идёт через представление с проверкой прав сотрудника;
- сам файл отдаёт nginx по `X-Accel-Redirect` — Django только проверяет
  доступ и не тратит рабочий процесс на передачу данных;
- проверяется не только расширение, но и фактический тип содержимого.

### 152-ФЗ

Вложения удаляются вместе с персональными данными при обезличивании по
сроку. Задача `purge_expired_leads` очищает поля — добавится удаление
файлов с диска.

### Доставка менеджеру

Вложением в письмо, если суммарный размер меньше 10 МБ, плюс ссылка на
заявку в админке. Крупные файлы — только ссылкой.

## 3. Отзывы

### Три разных сущности, которые нельзя смешивать

**Собственные отзывы** — то, что менеджер собрал у клиентов с их согласия.

```
Review    имя, должность, компания, город, оценка 1–5, текст,
          техника (необяз.), услуга (необяз.), источник,
          дата, опубликован
```

**Рейтинги площадок** — социальное доказательство со ссылкой на источник.

```
ReviewSource   площадка (2ГИС / Яндекс / Google), рейтинг,
               число оценок, ссылка, дата обновления, активна
```

Заполняется вручную: 2ГИС и Google не отдают отзывы через публичный API, а
обновляется такое раз в квартал за полминуты. Флаг активности позволяет
скрыть площадку, если она перестала быть живой.

**Виджет Яндекса** — официальный `iframe` из Яндекс.Карт, обновляется сам
каждые 72 часа. Работает без правки политики безопасности: `frame-src` для
`yandex.ru` уже открыт под карту проезда.

Обе модели живут в `apps/content/` — заводить приложение ради двух моделей
незачем.

### Микроразметка: важное ограничение

Разметка `AggregateRating` **не даёт звёзд в выдаче** для отзывов
организации о самой себе — таково правило Google, и оно распространяется и
на встроенные виджеты. Переносить в свою разметку рейтинги чужих площадок
прямо запрещено.

Поэтому:

- на странице `/otzyvy/` разметки **нет**;
- разметка `Review` ставится **только на карточке техники**, когда отзыв
  привязан к конкретной модели: это отзыв о товаре, а не самореклама, и он
  законен;
- звёзды у организации берутся из карточек Яндекс.Бизнеса и 2ГИС — это
  работа вне сайта, записана в `TODO.md`.

## 4. Подборки по диапазонам характеристик

Расширение существующей модели `CatalogLanding`:

```
CatalogLandingSpec    подборка, параметр, от, до
```

Несколько условий на подборку; хотя бы одна граница обязательна —
ограничение на уровне базы.

`CatalogLandingView.get_filters` подмешивает диапазоны в фильтры: механика
фильтрации переиспользуется целиком, ничего нового не пишется.

Подсчёт условий для правила индексации (`_landing_conditions`) сейчас
учитывает бренд, тип и категорию — добавятся диапазоны, иначе подборка с
диапазоном будет считаться «с посторонним фильтром» и уйдёт в `noindex`.

Подборки создаются **вручную в админке**: десяток-полтора под реальные
запросы, каждая со своим текстом. Автогенерация дала бы десятки почти
одинаковых страниц без уникального содержания — поисковик считает такое
малоценным и может понизить весь раздел.

Пример: `/katalog/ekskavatory-20-25-tonn/` → тип «Экскаватор» плюс
эксплуатационная масса от 20 000 до 25 000 кг.

## 5. Доставка

```
DeliveryOption    название, описание, срок, примечание,
                  порядок, активен
```

Живёт в `apps/company/` — это логистика филиала.

Демонстрационные данные под Дальний Восток: перегон своим ходом, автовоз,
железная дорога, морем через Ванино и Советскую Гавань.

Появляется на странице `/dostavka/` и блоком на карточке техники. Для
региона с такими расстояниями это вопрос первого разговора, и отвечать на
него нужно там, где смотрят машину.

## Что покрываем тестами

- арифметику лизинга, включая нулевой аванс, срок в один месяц и нулевое
  удорожание;
- проверку загружаемых файлов: расширение, размер, фактический тип;
- права доступа к вложению: посторонний не скачает;
- удаление вложений при обезличивании заявки;
- фильтрацию подборок по диапазонам и правило индексации;
- микроразметку отзыва на карточке техники и её отсутствие на странице
  отзывов;
- вывод блоков доставки и лизинга на карточке техники.

## Критерии готовности

- калькулятор лизинга считает контрольный пример из этого документа;
- файл проходит путь: форма → хранение → письмо → скачивание сотрудником →
  удаление при обезличивании;
- подборка по диапазону отдаёт ту же выдачу, что и фильтр вручную, и
  остаётся индексируемой;
- отзыв с привязкой к модели виден на её карточке с разметкой;
- покрытие тестами не ниже 90%, CI зелёный.
